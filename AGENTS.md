# support-bot

Универсальный сервис поддержки для нескольких продуктов. Исходники открыты.

- `src/index.ts`: пакет для интеграций, модель сообщений, Telegram, email, подписи webhook.
- `src/server.ts`: HTTP backend. Клиенты должны передавать ключ только через серверную часть своего продукта.
- PostgreSQL хранит темы и историю; одна тема на пару `service + userId`.
- Не сохранять токены, адреса пользователей и другие реальные данные в репозитории.
- Перед публикацией выполнять `npm test` и `npm audit --audit-level=high`.
- Production TV использует подписанный webhook в backend ТВ. Историю приложения хранит ТВ; перенос старой истории в базу бота не требуется. Проверять app → Telegram → webhook → app с push на реальном обращении.
